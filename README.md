# eslteacher.cl

Juegos para aprender inglés, organizados por curso.

- `index.html` — página principal. Los juegos de cada curso se listan en el arreglo `COURSES`.
- Cada carpeta (`5° BASICO`, `1° MEDIO`, `English Week 2026`, …) contiene los juegos de ese curso.
- Netlify publica automáticamente cada cambio que se sube a la rama `main`.
